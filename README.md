# GameHub

A free, fast browser-games platform. The project is intentionally static-first so it can run at essentially zero infrastructure cost while we validate the idea.

## Current MVP

- Responsive game portal UI
- Search and category filters
- Playable Reflex Rush
- Playable Memory Grid
- Game catalog placeholders ready for expansion
- GitHub Pages deployment workflow

## Engineering direction

Ship small, polished games, measure what players actually enjoy, then expand the catalog and monetization only after there is evidence of demand.
